# GRE Quant Lab

GRE Quantitative Reasoning için tarayıcıda çalışan deneme sınavları.

- 12 bölüm uyarlamalı deneme (Bölüm 1: 12 soru / 21 dk, Bölüm 2: 15 soru / 26 dk; Bölüm 2'nin zorluğu Bölüm 1'e göre seçilir)
- 3 konu testi
- Sınavdaki gibi Mark / Review, hesap makinesi (Transfer Display), adım adım çözümler ve kısayollar
- Sonuçlar ve geçmiş yalnızca kendi tarayıcında (localStorage) saklanır

Site: GitHub Pages üzerinden `index.html`. Yerelde denemek için klasörde `python3 -m http.server` çalıştırıp `http://localhost:8000` adresini aç (dosyayı çift tıklayarak açınca veriler yüklenmez).

Yeni deneme eklemek: `data/<id>/` klasörüne bölüm dosyalarını koy ve `data/tests.json` listesine kaydını ekle.
